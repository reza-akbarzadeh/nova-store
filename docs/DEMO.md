# دموی مستقل نوا

[باز کردن دمو](https://reza-akbarzadeh.github.io/nova-store/) · [تصاویر نسخهٔ وردپرس](https://reza-akbarzadeh.github.io/nova-store/gallery.html)

این دمو برای دیدن ظاهر و تجربهٔ رابط بدون نصب WordPress ساخته شده و روی GitHub Pages اجرا می‌شود.
قالب اصلی در پوشهٔ `nova/` قرار دارد؛ ساخت دمو هیچ تغییری در فایل‌های آن ایجاد نکرده است.

## ساختار

```text
docs/
  index.html          پوستهٔ دموی تعاملی
  gallery.html        گالری قبلی تصاویر واقعی وردپرس
  images/             تصاویر گالری
  demo/
    css/              کپی مستقل استایل قالب + تنظیمات دمو
    js/ui.js          کپی مستقل تعامل‌های عمومی قالب
    js/data.js        محصولات و مقاله‌های نمونه
    js/app.js         مسیرهای صفحات، جستجو، سبد و فرم‌های آزمایشی
    favicon.svg       آیکون دمو
```

تغییر فایل‌های دمو، قالب وردپرس را تغییر نمی‌دهد. استایل‌های کپی‌شده مستقل‌اند و با تغییرات بعدی قالب خودکار به‌روز نمی‌شوند.

## مسیرهای قابل امتحان

- `#/` صفحهٔ اصلی
- `#/shop` فروشگاه، فیلتر و مرتب‌سازی
- `#/product/1` جزئیات محصول
- `#/cart` سبد خرید آزمایشی
- `#/checkout` پایان مسیر خرید نمایشی
- `#/account` پیش‌نمایش فرم اطلاعات مشتری
- `#/magazine` جستجو و موضوع مقاله‌ها
- `#/article/headphones` خواندن مقاله

مسیرها با hash کار می‌کنند تا بارگذاری مستقیم و تازه‌سازی صفحات روی GitHub Pages به خطای ۴۰۴ نرسد.
هیچ مرحلهٔ build یا نصب پکیج برای اجرای دمو لازم نیست. پوشهٔ `docs` را با یک سرور HTTP استاتیک باز کنید.

## داده‌ها و حریم خصوصی

فقط شناسه و تعداد محصولات سبد در `nova-static-demo-cart-v1` در مرورگر ذخیره می‌شود.
تنظیم روشن/تیره از کلید `nova-theme` استفاده می‌کند. فرم حساب هیچ رمز یا داده‌ای به سرور نمی‌فرستد
و اطلاعات آن ذخیره نمی‌شود؛ برای امتحان ظاهر فرم از نام ساختگی استفاده کنید.

تسویهٔ نمایشی، دریافت وجه یا ساخت سفارش واقعی ندارد و فقط سبد دمو را خالی می‌کند.
مقاله‌ها و محصولات دادهٔ نمونهٔ محلی هستند؛ آن‌ها از دیتابیس وردپرس خوانده نمی‌شوند.
فونت مانند قالب اصلی از Google Fonts بارگذاری می‌شود و در نبود آن از فونت جایگزین استفاده می‌شود.

## بررسی‌ها

مسیرهای اصلی، جستجو، فیلتر و مرتب‌سازی، افزودن تعداد محصول، تغییر سبد، پایان خرید آزمایشی،
فرم حساب، تغییر تم و بستن منو با Escape در مرورگر آزمایشی بررسی شده‌اند.
چیدمان صفحهٔ اصلی در عرض‌های ۳۲۰، ۳۹۰، ۷۶۸ و ۱۴۴۰ پیکسل و صفحات داخلی در عرض ۳۹۰ پیکسل بررسی شده است.
این بررسی‌ها مربوط به دموی استاتیک هستند و جایگزین آزمون سفارش و پرداخت در نسخهٔ WordPress نیستند.
